# Ultrasound transducer design workbench

Interactive web application for the project *Computational Design and Multi-Objective Optimisation of
Piezoelectric Ultrasound Transducers for Biomedical Imaging*.

**Open it:** https://dvsnehal.github.io/transducer-design/

The one-dimensional KLM simulation engine runs entirely in your browser (Python via Pyodide), so no
installation is needed. The first visit downloads about 40 MB and takes 20 to 60 seconds to start.

This is a simulation study: no result has been compared with a laboratory measurement.

This repository holds only the built site. It is generated by `tools/build_site.py` in the project repository.
